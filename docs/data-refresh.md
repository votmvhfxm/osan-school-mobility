# 자동 갱신과 버스 노선 형상 (2026-10-23)

## 자동 수집에서 웹사이트 반영까지
매일 한국시간 04:17에 GitHub Actions가 공동주택·정류장·버스 노선·배차·공식 노선형상을 수집합니다.
검증 성공 시 공개 파일 목록만 main에 커밋합니다. 실패하면 기존 공개 데이터를 유지합니다.
사이트는 최신 공개 GitHub 스냅샷을 읽어 정적 사이트 재배포 지연과 별개로 데이터가 갱신됩니다.
GitHub 일정과 CDN 캐시 때문에 실행·반영이 지연될 수 있으며 실시간 운행정보를 보장하지는 않습니다.
API 원천 자체의 갱신 속도를 앞당길 수는 없습니다. 화면에는 자료 조회일을 표시합니다.
버스 조회 후 3일이 지나면 갱신 지연 안내를 표시합니다.

## 한 번 필요한 비밀키 설정
https://github.com/votmvhfxm/osan-school-mobility/settings/secrets/actions 에
DATA_GO_KR_KEY, VWORLD_API_KEY를 Repository secrets로 저장해야 서버에서 수집할 수 있습니다.
로컬 .env는 GitHub에 업로드하지 않으며 이 설정으로 자동 복사되지 않습니다.
SCHOOLINFO_API_KEY도 설정하면 학교를 함께 조회하고 학교 조회일을 기록합니다.
학교 키가 없으면 기존 학교 자료를 보존하고 조회일 미확인으로 표시합니다.
도로망·횡단보도·보호구역·사고 자료는 현재 별도 갱신 대상입니다. 최신으로 갱신되었다고 표시하지 않습니다.
키 값이나 .env 파일을 코드·데이터·아티팩트에 포함하지 않습니다.

## 버스 경로 수정
기존 결과는 실제 노선의 정류소를 직선으로 연결하거나 보행망을 버스 경로로 추정했습니다.
이제 GBIS getBusRouteLineListv2에서 수집한 실제 노선형상을 사용합니다.
왕복·순환 순서를 고려해 정류소 전체를 형상 좌표에 정렬하고 승차~하차 구간을 자릅니다.
승차 구간 길이도 형상 길이로 계산합니다. 이동시간은 평균속도와 배차 기반 추정이며 실시간 도착정보가 아닙니다.
형상이 없거나 정렬되지 않는 경우 버스 선을 임의로 만들지 않습니다.
조회 가능한 직행 노선이 없으면 버스 결과가 없다고 표시합니다. 환승 경로는 아직 지원하지 않습니다.
전체 형상은 한 번만 저장하고 각 결과는 구간 인덱스로 참조해 대용량 중복을 줄입니다.
이번 검증: 정류장 414개, 노선·형상 131개, 공식 형상 좌표 113,107개.
버스 통학 결과 3,437개 모두 공식 형상의 승하차 구간을 참조합니다.
