# 오산 통학

> **오산시 초·중학생의 더 안전하고 편안한 통학을 돕는 데이터 기반 지도 서비스**

2026 한신 AI·SW 페스티벌 AX 라이프케어 챌린지 지정공모 4번 **「학생 안전통학 AI 지도」** 출품작입니다.

이 웹사이트는 오산시 아파트 단지와 초등학교·중학교 사이의 통학 상황을 한눈에 보여 주고, 어디부터 보행환경과 대중교통을 개선하면 좋을지 제안합니다. 단순히 길찾기만 제공하는 것이 아니라, 여러 통학 경로를 오산시 전체 데이터와 함께 분석해 **통학 부담이 큰 위치와 그 이유**를 설명하는 것이 핵심입니다.

## 1. 이 웹사이트에서 해결하려는 문제

오산시의 학생과 보호자는 다음과 같은 질문에 답하기 어렵습니다.

1. 우리 집에서 학교까지 실제로 얼마나 걸리는가?
2. 가장 짧은 길이 항상 가장 안전한 길인가?
3. 어느 도로에 학생 통학이 집중되는가?
4. 사고·도로 구조·횡단 환경을 고려했을 때 어디부터 개선해야 하는가?
5. 버스정류장을 추가하거나 학교 후보지를 검토한다면 어느 위치가 효과적인가?

**오산 통학**은 이 질문에 답하기 위해 아파트 단지, 오산시 초·중학교, 보행 도로망, 횡단보도, 어린이보호구역, 사고다발지역, 버스정류장 데이터를 하나의 지도와 분석 화면으로 연결합니다.

## 2. 주요 기능

### 2.1 개선 위치 추천

오산시 전체 통학 분석 결과를 바탕으로 예산과 행정 역량을 먼저 투입할 위치를 제안합니다.

1. **보행 환경**
   - 여러 통학 경로가 겹치는 도로 구간을 우선순위로 표시합니다.
   - 차량 통행 도로 유형과 차로 수, 교차로, 횡단보도와 무신호 횡단보도, 어린이보호구역 포함 여부를 근거로 개선 필요성을 설명합니다.
   - 지도와 오른쪽 순위 카드가 연결되어 번호를 클릭하면 서로 같은 후보를 선택합니다.
   - 선택한 구간은 진하게, 나머지 후보는 반투명하게 표시해 위치를 쉽게 비교할 수 있습니다.
   - 카드 하단에는 대표 단지명과 함께 해당 구간의 보행환경 개선으로 영향을 받는 단지 수를 요약합니다.

2. **버스정류장**
   - 통학 부담이 큰 단지 주변의 정류장 후보를 표시합니다.
   - 정류장 위치와 주변 통학 수요를 바탕으로 배치·개선 검토 우선순위를 제안합니다.
   - 현재 버스 노선 상세·배차 원본이 확보되지 않은 경우에는 정류장 위치와 거리 기반의 추정 결과임을 명확히 표시합니다.

3. **학교 위치**
   - 새 학교가 확정된 위치를 표시하는 기능이 아니라, 현재 통학 부담이 큰 권역을 학교 후보 검토 순서로 보여 줍니다.
   - 단지와 기존 학교의 통학 부담을 종합해 학교 신설·배치 검토가 필요한 권역을 찾는 데 활용할 수 있습니다.

### 2.2 우리 집 통학길

출발 단지와 도착 학교를 직접 선택해 개인 통학 상황을 확인하는 화면입니다.

1. 오산시 아파트 단지를 검색하거나 목록에서 선택합니다.
2. 초등학교·중학교를 선택합니다.
3. 도보 또는 버스 시나리오를 선택합니다.
4. 지도에서 통학 경로, 위험 구간, 학교 위치를 확인합니다.
5. 소요시간, 이동거리, 통학 부담 지수, 위험 구간 길이와 개수를 비교합니다.

처음 화면은 특정 단지나 학교를 임의로 선택하지 않고 비워 둡니다. 사용자가 직접 출발지와 목적지를 선택해야 해당 통학 결과가 표시됩니다.

### 2.3 통학 부담 지수

단지와 학교의 조합마다 통학 상황을 비교할 수 있도록 다음 요소를 함께 반영한 지수를 계산합니다.

- 통학 소요시간
- 이동 경로의 위험도
- 버스 이용 시 대기·환승 부담

지수는 행정·기획 단계에서 여러 조합의 상대적인 부담을 비교하기 위한 값입니다. 실제 현장의 체감 시간과 안전을 대신하는 확정 판정이 아니며, 최종 시설 설치나 노선 결정 전에는 현장 조사가 필요합니다.

### 2.4 최단 경로와 안전 경로

- **최단 경로**: 거리 기준으로 가장 짧은 보행 경로입니다.
- **안전 경로**: 위험도가 높은 구간을 더 큰 비용으로 계산해 위험 구간을 줄이는 경로입니다.
- 우회가 지나치게 길어지거나 위험 구간이 실제로 줄지 않으면 안전 경로를 억지로 추천하지 않고 최단 경로를 사용합니다.

따라서 사용자는 “가장 짧은 길”과 “조금 돌아가더라도 위험을 줄인 길”을 함께 이해할 수 있습니다.

## 3. 화면에서 얻을 수 있는 정보

1. **개인 통학 정보**: 선택한 단지에서 학교까지의 예상 시간, 거리, 도보·버스 시나리오.
2. **안전 정보**: 경로에 포함된 위험 구간의 개수와 길이, 위험 구간의 지도 위치.
3. **개선 우선순위**: 많은 학생의 경로가 지나는 도로와 통학 부담이 큰 권역.
4. **위험 근거**: 차량 통행 도로 유형, 차로 수, 교차로, 횡단보도·무신호 횡단보도, 어린이보호구역 여부.
5. **수혜 범위**: 개선 구간을 이용하는 관련 단지와 학교, 영향을 받는 단지 수.
6. **대중교통 검토 정보**: 통학 부담이 큰 단지 주변의 정류장 후보와 배치 검토 사유.
7. **학교 수요 정보**: 학교 후보 검토가 필요한 권역과 그 권역을 우선 검토해야 하는 이유.
8. **행정·현장 조사 참고 정보**: 데이터로 먼저 확인할 위치를 좁히고, 이후 현장 확인·주민 의견·시설 가능성 검토를 진행할 수 있습니다.

## 4. 데이터와 분석 방법

### 4.1 분석 범위

- 지역: **경기도 오산시**
- 학교급: **초등학교·중학교**
- 출발지: 오산시 아파트 단지
- 지도·경로: 오산시 보행 도로망과 저장된 통학 분석 결과

학교알리미 수집 과정은 경기도 코드 `41`, 오산시 코드 `41370`, 초등학교·중학교 학교급으로 제한합니다. 고등학교와 다른 시·군·구 데이터는 현재 분석 범위에 포함하지 않습니다.

### 4.2 위험도 산정

위험도는 화면에 단순한 숫자만 보여 주기 위한 값이 아니라, 도로 환경을 비교하기 위한 내부 분석값입니다. 현재 규칙 기반 분석에서는 다음 요소를 사용합니다.

1. 도로 등급과 차량 통행 가능성이 높은 도로인지 여부
2. 차로 수
3. 보행 전용 도로인지 여부
4. 교차로 수
5. 횡단보도 수와 무신호 횡단보도 수
6. 신호 횡단보도 비율
7. 어린이보호구역 안·밖 여부

사고다발지역 데이터가 확보된 경우에는 도로에서 사고다발지역까지의 거리 기반 라벨을 함께 활용할 수 있습니다. 현재 데이터가 충분하지 않은 경우에는 위 도로·횡단·보호구역 피처를 이용한 규칙 기반 점수로 대체하며, 화면에는 사람이 이해할 수 있는 설명으로 변환해 표시합니다.

### 4.3 통학 부담 계산

```text
통학 부담 지수 =
  시간 부담 40% +
  경로 위험 부담 40% +
  버스 대기·환승 부담 20%
```

- 도보 속도는 분당 72m를 기준으로 계산합니다.
- 경로 위험 합은 각 도로 간선의 위험도와 길이를 함께 반영합니다.
- 위험도 0.6 이상인 연속 간선은 하나의 위험 구간으로 묶습니다.
- 버스 원본이 없는 경우 버스 결과는 실제 시간표가 아닌 거리 기반 추정값입니다.

## 5. 사용한 API·데이터 서비스

아래는 프로젝트에서 발급·연결해 사용한 API 목록입니다. **TMAP 보행자 경로 API는 사용 목록에서 제외**했습니다.

1. **네이버 클라우드 Maps Dynamic Map**
   - 배경지도, 지도 확대·축소, 단지·학교·정류장·추천 위치·경로 표시
   - 브라우저에는 Client ID만 사용하며 Client Secret은 넣지 않습니다.

2. **경기버스정보시스템(GBIS) 정류소 조회 API**
   - 오산시 주변 버스정류장 좌표와 정류장 정보

3. **경기버스정보시스템(GBIS) 버스노선 조회 API**
   - 버스 노선과 경유 정류장 정보
   - 현재 저장된 원본에는 노선 상세가 충분하지 않아 일부 화면은 거리 기반 추정으로 동작합니다.

4. **국토교통부 공동주택 단지 목록제공 서비스**
   - 오산시 아파트 단지 목록과 단지 코드

5. **국토교통부 공동주택 기본 정보제공 서비스**
   - 단지별 주소, 세대수 등 기본정보

6. **브이월드 주소 검색·좌표 변환 API**
   - 공동주택 주소를 위도·경도 좌표로 변환

7. **학교알리미 Open API**
   - 오산시 초등학교·중학교 기본정보, 학교 좌표·학교급·학교 관련 공시정보 수집

8. **전국횡단보도 표준데이터 API**
   - 횡단보도 위치, 신호 여부 등 보행환경 피처

9. **전국어린이보호구역 표준데이터 API**
   - 어린이보호구역과 대상 시설 위치 정보

10. **한국도로교통공단 교통사고정보개방시스템 보행자 교통사고 다발지역 API**
    - 보행자 사고다발지역 위치·사고 정보

11. **OpenStreetMap 보행 도로망 데이터**
    - 오산시 보행 가능한 도로 네트워크와 도로 유형
    - API 키가 필요한 서비스가 아니라 OSM 데이터를 수집·저장해 사용합니다.

## 6. 로컬에서 실행하기

### 6.1 준비

Python 3.10 이상을 권장합니다.

```bash
pip install pandas geopandas osmnx scikit-learn requests
```

### 6.2 지도 화면 실행

```bash
python serve.py
```

브라우저에서 [http://localhost:8000/web/](http://localhost:8000/web/)을 엽니다.

- 네이버 Maps Client ID가 없거나 도메인 등록이 되지 않아도 좌표 기반 개요와 분석 패널은 확인할 수 있습니다.
- 시연 화면은 미리 계산한 `data/index-lite.json`, `data/index.json`, `data/priority_segments.csv`를 읽습니다.
- 브라우저에서 공공 API를 매번 호출하지 않으므로 초기 로딩과 API 호출량을 줄였습니다.

### 6.3 데이터 다시 생성

API 키는 루트 `.env`에만 저장합니다. `web/config.js`에는 브라우저 공개용 네이버 Maps Client ID만 둡니다.

```bash
python scripts/fetch_osm.py
python scripts/fetch_public.py all
python scripts/fetch_schoolinfo.py
python scripts/fetch_bus.py
python scripts/fetch_apartments.py
python scripts/build_edges.py
python model/train_risk.py
python scripts/build_index.py
```

데이터 수집 API의 승인 상태나 호출 제한에 따라 일부 단계가 실패할 수 있습니다. 기존에 정상 생성된 데이터는 별도로 백업하고, 실패한 수집 단계 때문에 기존 결과를 비정상적으로 덮어쓰지 않도록 확인한 뒤 다시 생성합니다.

## 8. 데이터 해석 시 주의사항

1. 지도 결과는 정책 결정을 자동 확정하는 값이 아니라 **개선 후보를 좁히기 위한 분석 결과**입니다.
2. 단지와 학교 좌표는 대표 좌표일 수 있으므로 실제 출입구와 차이가 날 수 있습니다.
3. 버스 노선·배차 원본이 충분하지 않은 화면의 버스 시간과 정류장 추천은 추정값입니다.
4. 보행 위험도는 도로 데이터와 공개 데이터를 기반으로 한 모델·규칙 결과이며, 현장 조사를 대신하지 않습니다.
5. 실제 사업 시행 전에는 현장 보행 조사, 주민·학생 의견, 토지·시설 설치 가능 여부, 최신 사고·교통 데이터를 함께 확인해야 합니다.

## 9. 보안 및 키 관리

- `.env`와 비밀 API 키는 Git에 커밋하지 않습니다.
- 네이버 Maps Client ID는 브라우저에서 사용되는 공개 식별자이지만, 네이버 클라우드 콘솔에 실제 배포 도메인을 등록해야 합니다.
- 네이버 Maps Client Secret, 공공데이터 인증키, 교통사고 API 키는 `web/config.js`에 넣지 않습니다.
- 배포 시에는 Vercel 환경변수와 네이버 클라우드 Web 서비스 URL 허용 목록을 확인합니다.
- 자세한 발급·승인·호출 제한 정보는 [API 설정 가이드](API_설정_가이드.md)를 참고합니다.
