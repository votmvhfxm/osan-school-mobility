# 세교2지구 통학 부담 지수 (학생 안전통학 AI 지도)

2026 한신 AI·SW 페스티벌 AX 라이프케어 챌린지 · 지정공모 4번(학생 안전통학 AI 지도) 출품작.

오산시 아파트 단지에서 오산시 초등학교·중학교까지의 통학 부담을 **단지 × 학교** 조합별로 점수화하고, **최단 경로와 위험 구간을 피하는 안전 경로**를 비교해 네이버 지도 위에 보여 준다. 화면 문구의 관점은 "통학 부담이 큰 구간부터 지원"이다.

## 빠른 실행 (지도 화면)

```bash
# 1) 네이버 Maps Client ID 넣기 (web/config.example.js → web/config.js 로 복사 후 키 입력)
# 2) 저장소 루트에서 정적 서버 실행
python serve.py
# 3) 브라우저에서 http://localhost:8000/web/
```

- 네이버 클라우드 **Maps > Application**에서 Dynamic Map과 Web 서비스 URL을 등록하고 `web/config.js`의 `window.NAVER_MAP_CLIENT_ID`를 입력한다. Client Secret은 넣지 않는다.
- 키가 없거나 지도 인증에 실패해도 좌표 기반 경로 개요와 분석 패널을 볼 수 있다.
- 시연 화면은 미리 계산해 둔 `data/*.json`, `data/*.csv`만 읽고 외부 API를 부르지 않는다. 네이버 지도 SDK 로드만 예외다.
- 화면과 수집 파이프라인은 **오산시·초등학교·중학교**로 범위를 고정한다. 학교알리미는 `경기도(41)·오산시(41370)`과 학교급 `02/03`으로 수집하고, 타 시군구·고등학교 응답은 저장하지 않는다. 연령 수요를 추가할 경우에는 초등학생·중학생 연령대만 사용한다.

## 로컬에서 확인하기

```bash
python serve.py
```

학교 목록을 갱신하려면 `python scripts/fetch_schoolinfo.py`를 먼저 실행하고, 그 다음 `python scripts/build_index.py`를 실행한다. 아파트 단지는 국토교통부 공동주택 기본정보 API의 별도 활용 승인이 필요하며, 승인 전에는 현재 검증된 9개 단지만 유지한다. 버스는 정류장 좌표 329곳을 수집했지만 노선 상세 API가 별도 승인되지 않아 현재 경로 계산은 비활성 상태다.

브라우저에서 [http://localhost:8000/web/](http://localhost:8000/web/)을 열고 다음 흐름을 확인한다.

1. 지도 또는 좌표 기반 개요가 표시되는지 확인한다. 네이버 지도 인증이 실패해도 분석 화면은 동작해야 한다.
2. `개선 위치 추천`에서 보행 환경의 우선순위 카드와 지도 번호가 선택에 따라 바뀌는지 확인한다.
3. `개선 전후 비교`에서 출발 단지·도착 학교를 바꿔 시간, 거리, 위험 구간 값이 갱신되는지 확인한다.
4. `우리 집 통학길`에서 단지를 바꿔 세 학교의 부담 지수를 비교한다.

API 키를 다시 사용해 데이터를 만들 때는 루트 `.env`에만 저장하고, 브라우저 공개 파일에는 Client ID 외의 비밀키를 넣지 않는다.

무료량은 대표 계정 기준 Dynamic Map 월 600만 건이며, 여러 앱 사용량이 합산된다. 초과 과금을 막으려면 콘솔에서 앱별 한도를 설정한다. 자세한 발급·한도·키 설정은 [API 설정 가이드](API_설정_가이드.md)를 참고한다. 계정 설정과 실제 인증은 아직 미완료다.

## 전체 파이프라인 (데이터 다시 만들 때)

```bash
pip install pandas geopandas osmnx scikit-learn requests
cp .env.example .env          # 키 입력
python scripts/fetch_osm.py                 # OSM 보행 도로망 (키 불필요, 이미 data/raw 에 포함)
python scripts/fetch_public.py all          # 어린이보호구역·횡단보도·TAAS 사고다발지 (DATA_GO_KR_KEY)
python scripts/fetch_bus.py # GBIS 정류장·노선·배차 (DATA_GO_KR_KEY, data/raw/bus_api_cache.json 재사용)
python scripts/build_edges.py               # 간선 피처 → data/edges.gpkg
python model/train_risk.py                  # 구간 위험도 → data/edge_risk.csv, model/metrics.json
python scripts/build_index.py               # 지수·경로·우선순위 → data/index.json, data/priority*.csv
```

공공데이터 파일이 없으면 각 단계는 그 부분을 건너뛰고 진행한다. 예를 들어 횡단보도는 OSM 태그로 대체하고, 버스 시나리오는 생략한다.

## 통학 부담 지수 산식

```
지수 = 100 × ( 0.4 × 소요시간/최댓값 + 0.4 × 경로위험합/최댓값 + 0.2 × 버스대기·환승/최댓값 )
```

- **소요시간**: 도보는 경로 길이 ÷ 72m/분이다(1km ≈ 13.9분, 중학생 보행속도 약 1.2m/s). 버스는 도보(집→정류장) + 대기(첨두 배차 ÷ 2) + 승차(정류장 간 거리 ÷ 20km/h + 정류장당 0.3분) + 도보(정류장→학교)로 계산한다.
- **경로 위험 합**: Σ(간선 위험도 × 간선 길이 ÷ 100m)
- **위험 구간**: 위험도 0.6 이상인 간선이 이어진 구간
- **정규화**: 전체 조합(현재 학교 + 개교 예정 학교, 도보·버스)의 최댓값으로 나눈다. 최솟값을 0으로 만들지 않아서 "몇 배" 비교를 할 수 있다.
- **대표값**: 도보 시나리오와 버스 시나리오 중 지수가 낮은 쪽을 쓰고, 둘 다 저장한다.
- **가중치 근거**: 공모 주제가 "시간"과 "안전"을 함께 다루므로 두 항목에 같은 가중치(0.4)를 줬다. 버스 대기는 버스 이용자에게만 해당하는 보조 항목이라 0.2로 뒀다. 가중치는 `scripts/build_index.py` 상단 상수에서 바꿀 수 있다.

### 안전 경로
- 비용 = 길이 × (1 + 2 × 위험도 + 6 × [위험 구간 여부])로 두고 최소 비용 경로를 찾는다.
- 안전 경로는 최단 경로보다 20% 이내로 길면서 위험 구간 길이가 실제로 줄어들 때만 추천한다. 그 외에는 최단 경로를 그대로 추천한다.

## 구간 위험도 모델

- 피처(간선 단위): 도로 등급, 차로 수, 보행 전용 여부, 간선 길이, 교차로 수, 횡단보도 수, 무신호 횡단보도 수, 신호 비율, 어린이보호구역 포함 여부
- 라벨: TAAS 사고다발지역이 간선 반경 30m 안에 있으면 1. 인근 사고 건수는 라벨 누설을 막기 위해 피처에서 뺐다.
- 학습: 오산시 전체 간선으로 로지스틱 회귀와 그래디언트 부스팅을 학습한다. 약 500m 격자 단위 공간 교차검증으로 AUC를 비교하고, 더 나은 모델의 확률을 분위로 바꿔 0~1 위험도로 쓴다.
- **양성 간선이 30개 미만이면** 학습 모델 대신 **규칙 기반 점수식**을 쓴다. 가중치는 도로 위계 0.40, 무신호 횡단 0.25, 교차로 0.20, 보호구역 밖 0.15다. 이 경우 사고다발지와 비교한 AUC만 참고로 남긴다.
- **현재 상태 (2026-10-14)**: 공공데이터 키 발급 전이라 OSM 도로망만으로 규칙 점수를 썼다(`model/metrics.json`의 `mode: rule`). 키를 받으면 위 파이프라인을 다시 돌려 이 절을 갱신한다.

## 한계

- **단지 좌표는 단지 영역의 중심점**이다. 실제 출입구와 다를 수 있다. 세 단지(한신더휴, 우미린 센트럴시티, 라프리미어)는 좌표가 없어 아직 빠져 있다.
- **도로망은 OSM 기준**이다. 신규 택지라 일부 보행로가 빠져 있을 수 있고, 보도(sidewalk) 태그는 오산시에 하나도 없어서 보도 유무를 피처로 쓰지 못했다.
- **중학군은 2025학년도 고시 기준**(대호중·오산중·가수중)이다. 2027학년도 개정안이 나오면 바꿔야 한다.
- **사고 데이터 규모**: TAAS는 사고다발지(집계 구역)만 공개하므로 라벨이 적다. 이 경우 규칙 점수식으로 대체하고 그 사실을 표시한다.
- **버스 대기**는 첨두 배차 간격의 절반으로 근사했다. 실측값(`data/field/bus_wait_obs.csv`)이 있으면 그것으로 바꾼다. 환승 경로는 다루지 않는다.
- **세교2-1 개교 효과**는 해당 학교가 중학군에 편입되고 학교별로 균등하게 추첨된다는 단순 가정을 쓴 비교다. 실제 배정 규칙은 교육지원청 고시를 따른다.
- 이 결과는 직선거리 간이 계산을 실제 보행 경로로 보정한 **사전 검토 자료**다. 현장 확인을 대신하지 않는다.
